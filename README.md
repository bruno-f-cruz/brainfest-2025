# brainfest-2025

1. Download bonsai from the official website: [https://bonsai-rx.org](https://bonsai-rx.org/docs/articles/installation.html)
2. Launch the workflow by double-clicking `./src/demo.bonsai` or, to be safe, run:
```cmd
.bonsai/bonsai.exe ./src/demo.bonsai
```

In the workflow, the only "knob" you may need is the ComPort to the treadmill device. This can be set at the top level of the workflow by accessing the right panel under "port".
